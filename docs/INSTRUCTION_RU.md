# Подробная инструкция

## Перед началом
На DOOGEE S97 Pro включите Параметры разработчика → Отладка по USB.

## Порядок кнопок
**Client (DOOGEE):** просто запустите приложение и оставьте открытым.

**Host:**
1. Найти DOOGEE.
2. Подключить ADB.
3. На DOOGEE подтвердить RSA.
4. Проверить ADB.
5. После успешной проверки работают кнопки перезагрузки.

Для отчётов Client Link:
1. Запустить Client USB (AOA).
2. Подождать переподключение USB 2–5 секунд.
3. Найти DOOGEE.
4. Открыть Client Link.
5. PING.
6. Запросить отчёт Client.

## Если перезагрузка не сработала
Не нажимайте reboot до сообщения `ADB подключён`.
Сначала выполните Проверить ADB. Если нет ответа:
- переподключите кабель;
- убедитесь в USB debugging;
- подтвердите RSA;
- после перехода в AOA снова выполните поиск и ADB connect.

## Отчёты
После теста закройте/сверните оба приложения. Они сохранят отчёты в `Download/POSPReports`.
Загрузите сюда оба TXT: Host и Client.
