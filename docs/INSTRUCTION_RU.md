# POSP Research — порядок полного сбора
1. Запустите Client v0.3 на DOOGEE S97 Pro.
2. На Host откройте «Подключение» → «Подключить» → «Проверить связь».
3. Откройте «Полное исследование телефона».
4. Соберите Android + Client.
5. Перезагрузите в Bootloader/Fastboot, дождитесь повторного USB и соберите Fastboot.
6. Перейдите в Fastbootd и соберите данные dynamic/logical partitions.
7. Перейдите в Recovery и соберите доступные данные Recovery/ADB.
8. Вернитесь к «Отчёт» и сохраните `POSP_OS_Research_Bundle.zip`.
9. Нажмите «Отключить соединение».
10. Пришлите ZIP в чат для анализа полноты данных перед разработкой ОС.

Если режим недоступен, он фиксируется в `missing_data.txt`; уже собранные этапы не теряются.
