# Структура репозитория

## host-app
Android-приложение для второго телефона.
Функции: USB Host, ADB/Fastboot, диагностика, управление Client, установка ОС.

## client-app
Android-приложение для DOOGEE S97 Pro.
Функции: локальный сбор данных, связь с Host, безопасные команды режима загрузки.

## common
Общий протокол Host ↔ Client, JSON-схемы, SHA-256, модели данных.

## firmware/manifests
Манифесты совместимости и состава пакетов будущей POSP OS.

## tools
Скрипты подготовки, проверки и публикации.
