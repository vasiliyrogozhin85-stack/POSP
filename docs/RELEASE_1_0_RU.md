# POSP Research 1.0 — состав релиза

Host и Client переведены на версию 1.0 с сохранением package ID и dev signing material предыдущей линии 0.10/0.3.

Основной сценарий Host: Подключение -> Проверка связи -> Android -> Fastboot -> Fastbootd -> Recovery -> Отчёт -> Отключение.

Сбор является исследовательским и read-only. Автоматические flash, erase, OEM/critical unlock отсутствуют.

Перед практическим использованием необходимо проверить на реальном Host + DOOGEE S97 Pro переходы между всеми USB-режимами. Недоступные команды и файлы должны попадать в missing_data.txt, а не считаться успешными.
